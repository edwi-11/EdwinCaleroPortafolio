# PortfolioDeveloper
Portafolio sencillo en ASP.NET Core (.NET 8). Sirve `wwwroot/index.html` como sitio estático.

## Ejecutar
1. Abre `PortfolioDeveloper.csproj` en Visual Studio 2022.
2. Elige el perfil `http` o `IIS Express` y presiona F5.

## Dónde poner tus fotos
Reemplaza estos archivos por tus capturas (mismo nombre, formato .jpg, ideal 800x500):
- `wwwroot/images/proyectos/proyecto-1.jpg`
- `wwwroot/images/proyectos/proyecto-2.jpg`
- `wwwroot/images/proyectos/proyecto-3.jpg`

## Qué personalizar en `wwwroot/index.html`
Nombre, texto "Sobre mí", correo y enlaces de contacto, y el `href="#"` de cada "Ver proyecto".
Colores y fuente: variables al inicio de `wwwroot/css/style.css`.
